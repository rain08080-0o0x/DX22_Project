# 魔女の庭ライクゲーム

## 概要
ローグライクアクション  
四層のある階層の踏破を目指す。  
## ストーリー
    *未設定*
## ローグライク要素

```txt
各層では幾つかの部屋があり、  
それぞれをクリアすることにより  
バフやスキルを獲得  
さらなる強化が見込める。  
層が深くなるにつれ敵の体力と攻撃力、攻撃頻度、出現数が上昇  
スキルの種類によりシナジーが発動  
```

## 操作
四ボタンで攻撃と回避を行う  

Nintendo基準のボタン配置で解説  
|ボタン|攻撃種類|詳細|
|:---:|:---:|:----|
|Y|通常攻撃|職業によって変更自体は可能だが|
|B|回避|とりあえずは変更不可のボタン|
|A|スキル１|攻略により入手可能な攻撃手段|
|X|スキル２|攻略により入手可能な攻撃手段|
|-|-|-|
|右スティック|移動|移動以外の機能はなし|

## パラメーター

|パラメーター|初期値|概要|
|:---:|:---:|:---|
|体力|10|敵からダメージを受けると減り、0になるとゲームオーバー|
|攻撃力|5|敵に与えるダメージ。スキルは攻撃倍率で表示され、100が等倍となる(例:攻撃力が5で倍率が120なら与えるダメージは6となる)|
|クールタイム|100|それぞれの攻撃の基礎クールタイム。これが下がると全体のクールタイムもさがる|
|会心率/会心ダメージ|25%/200%|攻撃により確率で会心ダメージとなる。会心率を上げるバフ・報酬はない。|

### 属性
1. 雷
    1. 雷を纏っている武器で攻撃を行うと普通よりダメージが高くなる。一回分雷を消費する。
1. 風
    1. 風圧で敵を吹き飛ばす。場合によっては引き寄せる
1. 炎
    1. 炎を纏っている武器で攻撃すると本来よりダメージが高くなる。
1. 水
    1. 敵の移動スピードが低下する
1. 無
    1. さまざまな効果をもたらす


## スキル
|名前|種類|説明|
|:---:|:---:|:---|
|雷撃斬|雷|剣に雷を纏い前方に攻撃を行う。攻撃後一回分の雷を纏う|
|風切|風|前方に剣撃を飛ばす|
|炎撃|炎|前方に炎を飛ばし、攻撃することにより剣に一定時間炎を纏う|
|水槍|水|前方一直線に圧縮した水を飛ばす。複数の敵を貫通可能|
|鼓舞|無|自己を鼓舞し攻撃力を増加させる|

## シナジーの種類
- 雷
    - 攻撃により敵を介して伝播する
    - 確率で消費しない
- 風 
    - 任意の場所に風域を設置し、敵をその場に固定する。
    - 
- 炎
    - 敵を燃焼し持続ダメージを一定時間与える
    - 地面を燃やしその上に立った敵にダメージを与える
- 水
    - 水エリアを設置し敵の動きを大幅に阻害する
- 無
    - 属性によるダメージを増加させる
    - 斬撃により敵を出血させ割合ダメージを与える。

# DX22_Project


## ゲームのタイトル

**DX22_Project**

本作は、Wave制の戦闘とローグライク強化を組み合わせた 3D アクションゲームです。  
プレイヤーはアリーナ内で敵の群れを突破し、強化を重ねながら高難度の戦闘に挑みます。

## ゲームの世界観

舞台は、限られた空間の中で連続戦闘を行う閉鎖型の戦場です。  
プレイヤーは次々に出現する敵を倒しながら、その場で得た強化を武器に先へ進みます。

シンプルな構成の中で、

- 敵の包囲をどうさばくか
- 回避の無敵をどこで切るか
- 強化選択で次の戦い方をどう変えるか

という判断が積み重なり、1プレイごとに違う攻略感が出るように設計しています。

## ジャンル

- 3D アクション
- Wave制サバイバル
- ローグライク強化型バトル

## 操作方法

### キーボード

| 操作 | 内容 |
|---|---|
| `W` `A` `S` `D` | 移動 |
| `Shift` | 回避 |
| `F` | 通常攻撃 |
| `Q` | スキル1 |
| `E` | スキル2 |
| `Esc` | ポーズ / メニュー表示 |
| `Enter` / `Space` | 各種決定 |

### コントローラー

| 操作 | 内容 |
|---|---|
| 左スティック | 移動 |
| Xbox `A` | 回避 |
| Xbox `B` | 通常攻撃 |
| Xbox `X` | スキル2 |
| Xbox `Y` | スキル1 |
| `START` | 決定 / メニュー決定 |
| `BACK` | 戻る / 一部メニュー操作 |

### 対応入力

- キーボード操作に対応
- `XInput` 対応コントローラーに対応
- `DirectInput` 認識のコントローラーにも対応
- キーボードとコントローラーのどちらでも同じゲームを進行可能

## ゲームの流れ

1. タイトル画面でゲーム開始
2. 難易度を選択（Easy / Normal / Hard）
3. ゲーム開始後、Waveごとに出現する敵を撃破
4. 勝利時はリザルトで強化候補を選択し、次の挑戦へ進行
5. 敗北時はリザルトから再挑戦またはタイトルへ戻る

現行版では、戦闘ループの中心は「敵を倒す -> 状況を立て直す -> 次Waveへ進む」という流れです。  
強化選択や難易度の違いにより、同じステージでもプレイ感が変化します。

## クリア条件と失敗条件

### クリア条件

- 各Waveの敵を全滅させる
- 最終Waveを突破する
- 勝利後、強化選択または次の進行へ移る

### 失敗条件

- プレイヤーのHPが0になる
- 敗北時はリザルトへ遷移し、再挑戦またはタイトルへ戻る

## ゲームの見どころ

### 1. 回避と間合い管理が重要な近接アクション

攻撃ボタンを連打するだけではなく、敵の接近や攻撃予兆に合わせて回避を切る必要があります。  
短い判断の積み重ねで被弾を抑えながら、攻撃を差し込む感覚が本作の基礎になっています。

### 2. Wave制によるテンポの良い戦闘構成

ステージを長く探索するのではなく、戦闘の密度を高めた構成にすることで、

- 1戦ごとの緊張感
- 短いサイクルでの成長実感
- 繰り返し遊びやすいテンポ

を狙っています。

### 3. 強化選択によるローグライク性

勝利時には強化候補から1つを選択できます。  
攻撃力、攻撃頻度、回避性能などが変化し、次の戦闘の立ち回りが変わります。

### 4. ボス戦の圧と読み合い

ボスは通常の敵とは異なり、広範囲攻撃、予兆、Breakゲージ、Broken状態などを持っています。  
ただ倒すだけではなく、「いつ削るか」「いつBreakを狙うか」という判断が重要です。

## プログラムの見どころ

### AABBベースで統一した当たり判定

本作のゲームプレイ判定は、AABB（軸平行ボックス）に統一しています。  
見た目の回転に引っ張られず、処理系を一本化することで、

- 判定の一貫性
- デバッグのしやすさ
- 調整の見通しの良さ

を確保しています。

攻撃判定、敵接触、敵弾、押し合いなど、主要な判定は同じ方針で処理されます。

### 敵AIの状態分岐

敵は単純な直進ではなく、状況に応じて行動を切り替えます。

- 徘徊
- 接近追従
- 攻撃予兆
- 攻撃実行

さらに、密集しすぎないように分離行動も入っており、敵同士が重なり続けないようにしています。  
これにより、画面が詰まりすぎず、複数体戦でも見やすい戦場を維持しやすくしています。

### ボスのフェーズ制とBreakシステム

ボスにはHPによるフェーズ変化を導入しています。

- HP 50%以下で必殺技を解禁
- HP 25%以下で攻撃頻度と必殺技頻度を上昇

また、HPとは別にBreakゲージを持ち、

- 1ヒットごとに一定量減少
- 0になると Broken 状態
- Broken 中は被ダメージ倍率が上昇
- 一定時間後に回復し、次回以降はゲージ上限が増加

という構成になっています。

単純な「HPを削るだけ」ではなく、Breakの管理を挟むことで、戦闘にメリハリが出るようにしています。

### ImGuiによるリアルタイム調整

本作は、ゲーム中の多数の値を ImGui から直接調整できます。

- プレイヤー攻撃
- 敵の行動
- Wave構成
- ボス挙動
- UI位置やサイズ

などを実行中に変更できるため、プレイフィールの改善やデバッグ効率の向上に大きく寄与しています。

特にボス周りでは、

- Breakゲージの位置・サイズ
- 通常時 / Broken時の被ダメージ倍率
- Broken復帰時間
- Breakゲージ初期最大値 / 最終最大値 / 回復ごとの上昇量

まで調整可能です。

### 入力処理の柔軟性

入力はキーボードだけでなく、`XInput` と `DirectInput` の両方に対応しています。  
入力層で吸収しているため、ゲームロジック側は共通の操作関数を呼ぶだけでよく、実装の見通しを保ったまま複数デバイスに対応しています。
